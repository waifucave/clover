# Alpha's assets: placeholders

Every asset Alpha ships today is a **placeholder**, pending open question 26 (who owns Alpha's art, and under what licence). Replace each with Alpha's owned asset before release.

| Asset | What it is | Licence |
| :- | :- | :- |
| `alpha.vrm` | A VRM 1.0 model generated by code: `plugins/clover/vrm/scripts/make-placeholder.ts` (`bun run placeholder` in `plugins/clover/vrm`). No images, no outside references. Its metadata names it "Alpha (placeholder model)", so the avatar always shows it with a credit line. | The VRM Public License 1.0, in both `licenseUrl` (three-vrm requires it) and `otherLicenseUrl`: one licence story. |
| `portrait.svg` | Alpha's portrait while the avatar loads, drawn by hand for this repository. No scripts, no outside references. | This repository's licence (Apache-2.0). |
| `../tab/meadow.svg` | The clover meadow under the stage in Alpha's tab, drawn by hand for this repository. No scripts, no outside references. | This repository's licence (Apache-2.0). |

None of them is copied from anywhere.
