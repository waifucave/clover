# Alpha's assets: placeholders

Every asset Alpha ships today is a **placeholder**, pending open question 26 (who owns Alpha's art, and under what licence). Replace each with Alpha's owned asset before release. Alpha's avatar is the Live2D one; the VRM stays as the VRM renderer's sample until lane D's manifest points Alpha's `avatar` at `live2d/alpha.model3.json`.

| Asset | What it is | Licence |
| :- | :- | :- |
| `live2d/alpha.model3.json`, `live2d/alpha.moc3`, `live2d/alpha.png` | **Alpha's avatar** (decision 87: Alpha is Live2D): a Live2D Cubism model generated by code, `plugins/clover/live2d/src/placeholder/model.ts` (`bun run placeholder` in `plugins/clover/live2d`). Flat shapes in Alpha's lilac: eyes that blink, a mouth that opens and widens or rounds for the vowels, shoulders that breathe. A version 3 `.moc3` written by Mochi2D's own `writeMoc`, and a 64×64 texture of colour cells. No outside references; a test checks the committed files are what the code writes. Shown by `plugins/clover/live2d` on Mochi2D. | This repository's licence (Apache-2.0). |
| `alpha.vrm` | A VRM 1.0 model generated by code: `plugins/clover/vrm/scripts/make-placeholder.ts` (`bun run placeholder` in `plugins/clover/vrm`). No images, no outside references. Its metadata names it "Alpha (placeholder model)", so the avatar always shows it with a credit line. | The VRM Public License 1.0, in both `licenseUrl` (three-vrm requires it) and `otherLicenseUrl`: one licence story. |
| `portrait.svg` | Alpha's portrait while the avatar loads, drawn by hand for this repository. No scripts, no outside references. | This repository's licence (Apache-2.0). |
| `../tab/meadow.svg` | The clover meadow under the stage in Alpha's tab, drawn by hand for this repository. No scripts, no outside references. | This repository's licence (Apache-2.0). |

None of them is copied from anywhere.
