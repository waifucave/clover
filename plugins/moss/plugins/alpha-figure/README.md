# MOSS's figure

MOSS's figure as an avatar pack for the bundled avatar plugin (`moss/character`): two entries in its point
`moss.character.packs`, which the avatar plugin offers in its Settings section and its renderers draw.

| File | What it is | Licence |
| :- | :- | :- |
| `live2d/alpha.model3.json`, `live2d/alpha.moc3`, `live2d/alpha.png` | Her 2D figure, a Live2D Cubism model generated by code (`plugins/moss/plugins/live2d/src/placeholder/model.ts`, `bun run placeholder` in `plugins/moss/plugins/live2d`); a test checks the committed files are what the code writes. | This repository's licence (Apache-2.0). |
| `vrm/alpha.vrm` | Her 3D figure, a VRM 1.0 model generated by code (`plugins/moss/plugins/vrm/scripts/make-placeholder.ts`). | The VRM Public License 1.0. |

Both are placeholders, pending open question 26 (who owns MOSS's art). A model of the person's own is never added here:
it stays in their home, where the avatar plugin keeps it.
